Reusable patterns

Copyable CSS snippets

Translate

.box {
  animation: slideBox 2.2s ease-in-out infinite alternate;
}

@keyframes slideBox {
  to { transform: translateX(calc(100% - 66px)); }
}

Pulse

.box {
  animation: pulseBox 1.7s ease-in-out infinite;
}

@keyframes pulseBox {
  50% { opacity: 1; transform: scale(1.18) rotate(8deg); }
}

Orbit

.orbit {
  animation: orbitPath 4s linear infinite;
}

@keyframes orbitPath {
  to { transform: rotate(360deg); }
}

Visual QA

Motion checklist

  • Animations use transform instead of layout-shifting properties.
  • Controls remain reachable on touch screens and keyboard navigation.
  • prefers-reduced-motion is respected for visitors who need calmer motion.
  • Theme changes preserve contrast and keep the examples readable.
